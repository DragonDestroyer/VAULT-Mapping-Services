# VAULT Mapping Services

Base 3D map for Vidiaville. Open `index.html` in a browser, or host the folder on Cloudflare Pages.

Controls match Fusion 360:
- Middle mouse drag: orbit
- Shift + middle mouse drag: pan
- Scroll: zoom
- View cube (top right): click a face to snap that side
- Home: reset the camera

The scene is a grey ground plane and one tall brown block. Live editing comes next.
